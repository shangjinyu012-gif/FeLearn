      元素、标签和属性

      看懂 HTML 代码，关键是能把一行代码拆成这几块。点击下面的按钮或代码片段。

      空元素：没有内容，也没有结束标签

      有些元素天生不包内容，只写一个标签就够了，例如 <img>、<br>、<hr>、<input>、<meta>、<link>。写成 <br /> 也可以，HTML5 里两种都对。

      嵌套：像括号一样成对关闭

      元素可以套元素，形成一棵"树"。先打开的后关闭，不能交叉。

      ✓ 正确嵌套
      <p>我<strong>很重要</strong></p>
      ✗ 交叉嵌套
      <p>我<strong>很重要</p></strong>

      所有元素都能用的全局属性

      属性作用例子
      id元素的唯一名字，整页不能重复。用于锚点跳转、JS 获取元素id="login-form"
      class分类名，可以多个、可以重复。CSS 主要靠它选中元素class="btn btn-primary"
      style直接写行内样式（一般不推荐，样式应放 CSS 文件）style="color:red"
      title鼠标悬停时显示的提示文字title="点我登录"
      hidden隐藏元素<p hidden>
      data-*HTML5 新增：存放自定义数据，给 JS 读取data-user-id="42"

      注释写法是 <!-- 这是注释 -->，浏览器不会显示它，常用来给代码写说明。

      03

      文本：标题、段落与强调

      网页上大部分内容都是文字。下面这些标签覆盖了 90% 的场景。

      文本标签
      要点

      标题标签按层级选，不按大小选。想要小字体的一级标题，用 CSS 改字号，不要因为字小就用 h4。搜索引擎和读屏软件靠 h1~h6 理解文章结构。

      易混

      <strong> 表示"重要"，<b> 只是加粗；<em> 表示"强调语气"，<i> 只是斜体。HTML5 推荐用有含义的 strong 和 em。

      04

      链接与图片

      "超文本"里的"超"，指的就是链接。预览里点击链接，会提示它将跳转到哪里。

      a 和 img

      a 标签的常用属性

      • href：要去的地址，必填。可以是网址、文件、#id（页内跳转）、mailto:、tel:。
      • target="_blank"：在新标签页打开，通常搭配 rel="noopener" 保证安全。

      img 标签的常用属性

      • src：图片地址，必填。
      • alt：图片的文字描述。图片加载失败时显示，读屏软件会读出来，搜索引擎靠它理解图片。每张图都应该写。
      • width / height：宽高（单位像素，不用写 px）。只写一个会按比例缩放。

      表单：前端和后端的接口

      09

      块级元素与行内元素

      这是学 CSS 布局前必须分清的概念。蓝色是块级元素，橙色是行内元素。

      两种元素的排列方式
      类型表现常见元素
      块级 block独占一行，宽度默认 100%，能设宽高div p h1~h6 ul ol li table form header main section footer
      行内 inline和别的元素排在一行，宽高由内容决定，设置宽高无效span a strong em code label
      行内块 inline-block排在一行，但能设宽高img input button select textarea
      嵌套规则

      块级元素可以包含行内元素，行内元素不要包含块级元素。特别注意：<p> 里不能放 <div> 或另一个 <p>，浏览器会自动把 p 提前关闭，导致结构错乱。HTML5 中 <a> 是例外，它可以包住一整块内容（比如一张商品卡片）。

            03

            层叠、继承与优先级

            CSS 的全称是“层叠样式表”。同一个元素被好几条规则同时命中、而且改的是同一个属性时，浏览器按下面的顺序决定听谁的。

            1. !important 最优先（尽量别用）。
            2. 其次比优先级：行内 style > ID > 类 / 属性 / 伪类 > 元素 / 伪元素。
            3. 优先级一样，后写的覆盖先写的。
            这段字最后是什么颜色？

            优先级计算器

            优先级是三个数字 (ID 数, 类数, 元素数)，从左往右逐位比较，左边的一位大就直接赢，不会“进位”。输入两个选择器比一比。

            换一组：

            继承：有些属性会传给子元素

            给 body 设置 color 和 font-family，整页文字都会跟着变，因为文字类属性（color、font-*、line-height、text-align 等）会被子元素继承。盒子类属性（width、padding、margin、border、background 等）不会继承，否则每一层都会多出一圈边框。

            避坑

            样式不生效时，打开浏览器开发者工具（F12）的 Elements 面板，选中元素看右侧 Styles：被划掉的那条就是“输了”的规则，上面那条是赢家。

            none隐藏，而且不占位置（visibility: hidden 也隐藏，但还占着位置）
            
          
            flex子元素按 Flex 规则排列，见第 07 节
            
          
            grid子元素按网格排列，见第 08 节
            
                    
      
            
      
            定位：把角标钉在卡片右上角

            position效果典型用途
            
        
          
            static默认值，正常排列，top/left 无效
            
          
            relative相对自己原来的位置偏移，原位置仍然占着给 absolute 子元素当参照物
            
          
            absolute脱离正常排列，相对最近的非 static 祖先定位角标、下拉菜单、弹出提示
            
          
            fixed相对浏览器窗口定位，滚动也不动回到顶部按钮、悬浮客服
            
          
            sticky平时正常排列，滚到指定位置就“粘”住吸顶导航、表头
            
                    
      
            
      
            元素叠在一起时，用 z-index 决定谁在上面，数字大的在上，只对定位过的元素有效。
            
    
            

    
    
            
      
            07
            Flexbox：一维排列的首选
            
      
            给父元素写上 display: flex，它的直接子元素就会排成一行。导航栏、按钮组、卡片一行排开，基本都用它。点下面的按钮，观察每个属性的作用。
            
      
            
        
            
        
            
        
            
        
            
      
            
      
            
        
            属性写在作用
            
        
          
            display: flex父元素开启 Flex 布局
            
          
            flex-direction父元素主轴方向：row 横排，column 竖排
            
          
            justify-content父元素主轴上怎么分布
            
          
            align-items父元素交叉轴上怎么对齐。justify-content: center 加 align-items: center 就是水平垂直居中
            
          
            flex-wrap父元素放不下时是否换行
            
          
            gap父元素子元素之间的间距
            
          
            flex: 1子元素占满剩余空间；几个子元素都写 1 就平分
            
          
            align-self子元素单独覆盖自己的 align-items
            
          
            order子元素改变显示顺序，不用改 HTML

            08
            Grid：二维网格布局
            
      
            Flex 管一行或一列，Grid 同时管行和列。整页的大框架、卡片墙、相册，用 Grid 最省事。
            
      
            
        
            自动换行的卡片墙拖动预览宽度，列数自动变
            
        

      
            
      
            用区域名字画出页面框架
            
      
            
        
            grid-template-areas试试把 aside 挪到左边
            
        

      
            
      
            怎么选
            内容沿一个方向排、数量不固定（导航链接、标签、按钮组）用 Flex；要行列对齐的二维结构（页面框架、卡片墙、表单两栏）用 Grid。两者经常嵌套使用：Grid 搭框架，框架里的小组件用 Flex。

            响应式：一套代码适配手机和电脑
            
      
            媒体查询 @media 让一段 CSS 只在满足条件时生效。拖动“预览宽度”滑块，看卡片从一列变成三列。
            
      
            
        
            移动优先的三栏卡片
            
        

      
            
      
              
        
            • 移动优先：先写手机样式，再用 min-width 给大屏幕加样式。手机上加载的 CSS 更少，思路也更清楚。
              • 
        
            • 常用断点：640px 大手机、768px 平板、1024px 笔记本、1280px 台式机。按内容需要定，不必死记。
              • 
        
            • 图片自适应：img { max-width: 100%; height: auto; }，图片永远不会撑破容器。
              • 
        
            • 别忘了 HTML 里的 viewport meta 标签，没有它手机会按电脑宽度缩小显示，媒体查询也不准。

            CSS 变量、过渡与动画
            
      
            变量让配色集中管理，过渡和动画让界面有反馈感。把鼠标移到预览里的按钮上。
            
      
            
        
            按钮与动画试试把 --brand 改成 #c8421a
            
        

      
            
      
            
        
            写法作用
            
        
          
            --name: 值定义 CSS 变量，一般写在 :root 里全局可用。暗色模式就是换一组变量值
            
          
            var(--name)使用变量
            
          
            transition属性变化时平滑过渡：transition: 属性 时长
            
          
            transform移动 translate、缩放 scale、旋转 rotate，不影响周围元素的排列
            
          
            @keyframes + animation定义并播放一段关键帧动画
            
          
            box-shadow阴影：x 偏移、y 偏移、模糊、颜色
            
          
            opacity不透明度，0 到 1
            
                    
      
            
      
            性能
            动画尽量只改 transform 和 opacity。改 width、top 这类属性会让浏览器每一帧重新计算布局，容易卡顿。
