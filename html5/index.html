    02

    元素、标签和属性

    看懂 HTML 代码，关键是能把一行代码拆成这几块。点击下面的按钮或代码片段。

    空元素：没有内容，也没有结束标签

    有些元素天生不包内容，只写一个标签就够了，例如 <img>、<br>、<hr>、<input>、<meta>、<link>。写成 <br /> 也可以，HTML5 里两种都对。

    嵌套：像括号一样成对关闭

    元素可以套元素，形成一棵"树"。先打开的后关闭，不能交叉。

    ✓ 正确嵌套
    <p>我<strong>很重要</strong></p>
    ✗ 交叉嵌套
    <p>我<strong>很重要</p></strong>

    所有元素都能用的全局属性

    属性作用例子
    id元素的唯一名字，整页不能重复。用于锚点跳转、JS 获取元素id="login-form"
    class分类名，可以多个、可以重复。CSS 主要靠它选中元素class="btn btn-primary"
    style直接写行内样式（一般不推荐，样式应放 CSS 文件）style="color:red"
    title鼠标悬停时显示的提示文字title="点我登录"
    hidden隐藏元素<p hidden>
    data-*HTML5 新增：存放自定义数据，给 JS 读取data-user-id="42"

    注释写法是 <!-- 这是注释 -->，浏览器不会显示它，常用来给代码写说明。

    03

    文本：标题、段落与强调

    网页上大部分内容都是文字。下面这些标签覆盖了 90% 的场景。

    文本标签
    要点

    标题标签按层级选，不按大小选。想要小字体的一级标题，用 CSS 改字号，不要因为字小就用 h4。搜索引擎和读屏软件靠 h1~h6 理解文章结构。

    易混

    <strong> 表示"重要"，<b> 只是加粗；<em> 表示"强调语气"，<i> 只是斜体。HTML5 推荐用有含义的 strong 和 em。

    04

    链接与图片

    "超文本"里的"超"，指的就是链接。预览里点击链接，会提示它将跳转到哪里。

    a 和 img

    a 标签的常用属性

    • href：要去的地址，必填。可以是网址、文件、#id（页内跳转）、mailto:、tel:。
    • target="_blank"：在新标签页打开，通常搭配 rel="noopener" 保证安全。

    img 标签的常用属性

    • src：图片地址，必填。
    • alt：图片的文字描述。图片加载失败时显示，读屏软件会读出来，搜索引擎靠它理解图片。每张图都应该写。
    • width / height：宽高（单位像素，不用写 px）。只写一个会按比例缩放。

    列表与表格

    导航菜单、商品列表、步骤说明，本质上都是列表。表格只用来展示二维数据，不要用它做页面布局。

    三种列表
    规则

    <ul> 和 <ol> 的直接子元素只能是 <li>。li 里面可以再放任何内容，包括另一个列表（多级菜单就是这样做的）。

    表格试试把 rowspan 改成 1
    标签含义
    table整张表格
    caption表格标题
    thead / tbody / tfoot表头区 / 主体区 / 表尾区
    tr一行（table row）
    th表头单元格，默认加粗居中（table header）
    td普通单元格（table data）
    colspan / rowspan单元格横向 / 纵向合并几格

    语义化标签：HTML5 最重要的变化

    以前整页都是 <div>，看代码猜不出哪块是导航、哪块是正文。HTML5 新增了一组"有名字"的容器。点击左边的区块。

    <header>
    <nav>
    <main>
    <article>
    <section>
    <section>
    <aside>
    <footer>

    同一个页面，两种写法

    以前：div 一把梭
    <div class="header">
  <div class="menu">...</div>
</div>
<div class="content">...</div>
<div class="footer">...</div>
    HTML5：一眼看懂
    <header>
  <nav>...</nav>
</header>
<main>...</main>
<footer>...</footer>

    语义化标签在外观上和 div 没有区别，好处在于：代码更好读、搜索引擎更懂你的页面（SEO）、读屏软件能让视障用户直接跳到导航或正文。打开下面的"标出元素"，看看每个标签占了哪块区域。

    一个博客页面
    怎么选

    先问"这块内容是什么"。是独立完整的一篇内容用 article；是一篇里的一个章节用 section；纯粹为了加样式、没有含义的包裹用 div（块）或 span（行内）。

    07

    表单：前端和后端的接口

    登录、注册、搜索、下单都靠表单把用户输入交给后端。这一节和你之后写后端直接相关。

    先空着点"提交"，看浏览器自带的校验提示；再填好所有必填项提交，预览会显示会发送给后端的数据。注意它们的键名来自哪个属性。

    注册表单HTML5 自带校验，不用写 JS

    表单里最关键的四个属性

    属性写在哪作用
    actionform数据提交到哪个地址，通常是后端接口，如 /api/register
    methodformget：数据拼在网址后面（适合搜索）；post：数据放在请求体里（适合登录注册）
    nameinput 等提交时数据的键名。没有 name 的输入框不会被提交，后端也就收不到
    id + forinput + labellabel 的 for 等于 input 的 id，点文字就能聚焦输入框，读屏软件也能读出这个框是干什么的

    HTML5 的 input 类型

    改一个 type，浏览器就会给出对应的输入控件、手机键盘和格式校验。

    type用途HTML5 新增
    text普通单行文本（默认值）
    password密码，输入显示为圆点
    email邮箱，自动校验格式✓
    number数字，可配合 min / max / step✓
    tel电话，手机上弹出数字键盘✓
    url网址，自动校验格式✓
    search搜索框✓
    date / time日期 / 时间选择器✓
    range滑块✓
    color颜色选择器✓
    checkbox多选框
    radio单选框，同一组的 name 必须相同
    file上传文件
    hidden隐藏字段，用户看不到但会被提交

    常用校验与辅助属性

    required 必填、placeholder 占位提示、minlength / maxlength 长度限制、min / max 数值范围、pattern 正则校验、disabled 禁用、readonly 只读、autofocus 自动聚焦、value 默认值。

    全栈提醒

    前端校验只是为了用户体验，用户可以绕过它。后端收到数据后必须再校验一遍。

    08

    多媒体：音频、视频和画布

    在 HTML5 之前，网页播放视频要装 Flash 插件。现在一个标签就够了。

    video、audio、canvas预览里没有真实音视频文件，只显示播放器外观
    写法作用
    controls显示播放、暂停、音量等控制条。不写就没有控制条
    autoplay自动播放。浏览器通常要求同时加 muted（静音）才允许
    loop循环播放
    poster视频加载前显示的封面图
    <source>提供多个格式，浏览器从上到下选第一个能播的
    <iframe>在页面里嵌入另一个网页，比如地图、B 站视频
    <svg>矢量图形，放大不失真，常用于图标
    知道名字即可

    HTML5 还带来了一批 JavaScript 接口：本地存储 localStorage、拖放 Drag and Drop、地理定位 Geolocation、WebSocket 等。它们写在 JS 里，学 JavaScript 时再展开。

    09

    块级元素与行内元素

    这是学 CSS 布局前必须分清的概念。蓝色是块级元素，橙色是行内元素。

    两种元素的排列方式
    类型表现常见元素
    块级 block独占一行，宽度默认 100%，能设宽高div p h1~h6 ul ol li table form header main section footer
    行内 inline和别的元素排在一行，宽高由内容决定，设置宽高无效span a strong em code label
    行内块 inline-block排在一行，但能设宽高img input button select textarea
    嵌套规则

    块级元素可以包含行内元素，行内元素不要包含块级元素。特别注意：<p> 里不能放 <div> 或另一个 <p>，浏览器会自动把 p 提前关闭，导致结构错乱。HTML5 中 <a> 是例外，它可以包住一整块内容（比如一张商品卡片）。
